Each department gets its own API key from the RHOAI Dashboard. The gateway routes requests by model and key to vLLM servers, enabling per-team attribution at the request level.

Every inference call is logged with input/output token counts, model name, latency, and cost. Split by department or view aggregate usage across the organization.

Perses Dashboards
OpenShift Console → Observe → Dashboards. Filter by subscription to isolate one team's usage. Filter by model to understand cost drivers.
